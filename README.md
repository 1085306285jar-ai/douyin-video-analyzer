# 抖音视频 AI 智能解析工具

Windows 10/11 本地桌面工具。粘贴抖音公开单视频、合集或博主主页链接后，程序读取公开媒体，在本机完成普通话转写、内容拆解和 TXT/Markdown 导出。

## 用户实际得到什么

- 一个 `抖音视频AI解析工具.exe`，无需安装 Python、FFmpeg、模型或其他插件。
- 单视频、合集、博主主页三类入口，自动识别分享文案中的链接。
- 本地 Faster-Whisper 中文语音转写；CPU `int8` 推理，不要求独立显卡。
- 本地结构化分析：核心主题、2—5 条观点、原文金句、内容属性、5 个标签。
- 批量队列、实时进度、取消任务、逐条容错、10 秒及以下内容过滤。
- 自动生成 UTF-8 TXT 原始文案、Markdown 分析报告和批量索引。
- 启动闪屏，避免大体积单文件首次解压时看起来“点了没反应”。

## 联网与隐私边界

“本地离线版”指 AI 处理离线，不代表互联网链接能在断网时读取。

- 联网仅用于访问用户主动粘贴的抖音公开页面及其媒体 CDN。
- 不调用 ChatGPT、云端转写、付费 API 或第三方解析网站。
- 链接、媒体、字幕和分析内容不上传给任何 AI 服务。
- 临时媒体在单条处理后删除；任务结束后清理整个临时目录。
- 风控兼容模式会使用一个独立 Edge 配置目录。若用户手动登录，登录状态只保存在本机，不读取个人 Edge 配置。
- 临时 Cookie 文件仅保留抖音域名项，并在任务结束后删除。

## 为什么有“Edge 兼容窗口”

抖音页面和风控会变化，公开主页/合集的翻页有时要求正常浏览器环境。程序按以下顺序处理：

1. 先用轻量提取器直接读取，成功时不打开浏览器。
2. 常规读取受限时，在用户勾选兼容模式的前提下打开独立 Microsoft Edge。
3. 用户如遇平台验证，可在窗口里手动完成；程序不会破解或自动绕过验证。
4. 兼容窗口从已经正常展示的页面收集公开视频，再交给本地转写链路。

Windows 10/11 通常自带 Microsoft Edge。用户也可以取消勾选兼容模式，此时风控内容会给出明确失败原因。

## 使用方法

1. 双击 EXE，闪屏结束后进入主界面。
2. 复制抖音分享文案或链接，点击“一键粘贴”。
3. 保持“自动识别”，或手动指定单视频/合集/博主主页。
4. 批量主页建议首次设置 10—20 个；确认稳定后再提高。
5. 点击“开始解析”。若独立 Edge 打开且出现验证，手动完成后等待程序继续。
6. 成功后在界面查看结果；文件已自动保存到 EXE 同级 `output` 文件夹。若同级目录不可写，会保存到当前用户本地数据目录。

## 真实性能预期

- 下载耗时取决于网络和平台页面响应。
- 转写耗时取决于视频时长与 CPU。中等配置 CPU 通常可接近实时或快于实时；不能承诺所有视频 10 秒内完成。
- 单文件包含 Python 运行时、本地模型、浏览器驱动与转写依赖，预计为数百 MB；启动时会先解压到系统临时目录，因此提供了即时闪屏。
- 当前默认 CPU 模型是 `faster-whisper-base`。它兼顾体积与速度；严重口音、多人重叠、强背景音乐仍可能影响准确率。

## 开发与测试

本地算法测试不需要下载模型：

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
```

目前自动化覆盖链接安全校验、分享文本提取、内容分析、原文金句约束、文件导出、防覆盖、批量跳过、取消与清理、浏览器响应解析及 Cookie 域名过滤。

## Windows 单文件构建

最终 EXE 必须在 Windows x64 上构建和验收。PyInstaller 产物绑定构建平台，Linux 不能可靠产出 Windows 版原生依赖。

构建机要求：Windows 10/11 x64、Python 3.12 x64、网络可访问 PyPI 与 Hugging Face（只在构建时下载依赖和模型）。

双击：

```text
build_windows.bat
```

构建脚本会自动：

1. 创建独立构建环境并安装锁定版本依赖；
2. 生成中文闪屏和 Windows 图标；
3. 下载并校验离线语音模型；
4. 运行全部自动化测试；
5. 生成单文件 EXE；
6. 运行打包后自检，确认模块、模型和输出目录均可用。

成功产物：

```text
dist\抖音视频AI解析工具.exe
```

仓库也包含 `.github/workflows/build-windows.yml`，可在 GitHub Actions 的 Windows 构建机上生成同一单 EXE。

## 发布前人工验收

- 两台干净 Windows 电脑各执行一次：Windows 10 x64、Windows 11 x64。
- 测试一个有效单视频、一个公开合集、一个公开博主主页。
- 覆盖无效链接、已删除、私密、无口播、10 秒短视频、网络中断、任务取消。
- 检查中文字体、窗口缩放、输出编码、任务期间界面响应。
- 使用 Windows Defender 扫描；商业分发前建议购买代码签名证书，减少 SmartScreen 提示。
